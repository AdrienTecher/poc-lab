    For the grown-up running it

    Built as short rounds on purpose — each one has a single clear win, movement, and an instant payoff so attention stays put. The fraction box updates live, so a wrong arrangement is corrected by the screen, not by you. Keep tempo low (around 80–90) so divisions are easy to count. Music notation already is fraction notation: whole, half, quarter, eighth, sixteenth — and "4/4" is a real fraction sitting on the T-8.

    Accessibility: every pad and control is keyboard-reachable (Tab + Enter/Space), colour is never the only signal, motion respects your "reduce motion" system setting, and the fraction readout is announced to screen readers. Body text uses Atkinson Hyperlegible, a typeface designed for readability.
